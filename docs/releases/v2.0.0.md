# arxgen v2.0.0

arxgen 2.0 stabilizes the external plugin SDK.

## Highlights

- Added the v2 plugin contract with metadata, capability declarations, compatibility checks, and generation hooks.
- Added external plugin loading for local files and installed npm packages through `--plugin`, `--plugins`, and `ARXGEN_PLUGINS`.
- Added clear validation and runtime errors for incompatible plugins and invalid generated-file results.
- Added plugin development documentation, lifecycle notes, capability matrix, and a minimal example plugin.
- Added contract, fixture, snapshot, and compatibility tests for the plugin SDK.

## Upgrade Notes

Built-in plugins remain available without configuration. External plugins should expose `metadata.apiVersion` with major version `2` and return generated files as `{ path, content }` objects.
